# Changelog

## 0.2.0 - 2026-10-24

- Moved desktop actions into a single Fuzzel launcher menu opened by SUPER.
- Made the default launcher the mouse-interactable application list, with DESU
  actions available through a side action menu and direct SUPER bindings.
- Added a native Quickshell notification drawer to the bar.
- Added the Lua Hyprland main config with SUPER workspace scrolling, terminal,
  screenshot, and awww wallpaper startup bindings.
- Fixed installed settings layout and reduced the wallpaper picker size.

## 0.1.0 - 2026-10-24

- Initial Quickshell bar with Hyprland workspaces, active window, tray, clock,
  audio controls, recorder state, clipboard, launcher, and wallpaper actions.
- Added Quickshell IPC lifecycle control through the `desu` CLI.
- Added relocatable installation, backups, diagnostics, and modular Hyprland
  integration examples.
